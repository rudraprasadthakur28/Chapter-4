# Python Chapter 4 — Lists and Tuples

This repository contains my practice programs and exercises from **Python Chapter 4**. This chapter focuses on working with lists and tuples, accessing their elements, and using their built-in methods.

## Topics Covered

### 1. Lists

Learn how to create and work with lists in Python.

Practice includes:

- Creating lists
- Accessing list elements
- Indexing
- Negative indexing
- Slicing lists
- Updating list elements
- Adding elements
- Removing elements
- Iterating through lists

Example:

```python
numbers = [10, 20, 30, 40]
```

### 2. List Methods

Practice commonly used list methods, including:

- `append()`
- `insert()`
- `remove()`
- `pop()`
- `sort()`
- `reverse()`
- `clear()`
- `count()`
- `index()`

### 3. Tuples

Learn how to create and work with tuples in Python.

Practice includes:

- Creating tuples
- Accessing tuple elements
- Indexing
- Negative indexing
- Slicing tuples
- Understanding immutable sequences

Example:

```python
numbers = (10, 20, 30, 40)
```

### 4. Tuple Methods

Practice the built-in methods available for tuples:

- `count()`
- `index()`
